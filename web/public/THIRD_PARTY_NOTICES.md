## Interstellar black-hole renderer

This project includes a derived shader integration inspired by
[sirxemic/Interstellar](https://github.com/sirxemic/Interstellar).

Copyright (c) 2015 Pim Schreurs. Licensed under the MIT License.

The original project is an interactive wormhole and black-hole simulation.
The portfolio integration adapts only the black-hole ray-bending and
accretion-disk rendering concepts for a Three.js scene. Its plasma pattern is
generated procedurally by this project; no texture from the source repository
is bundled.

## Clouds and sky (takram three-geospatial)

[@takram/three-clouds and @takram/three-atmosphere](https://github.com/takram-design-engineering/three-geospatial),
an implementation of Eric Bruneton's precomputed atmospheric scattering. Their cloud shape, detail, weather,
turbulence and blue-noise textures are bundled in `textures/clouds`.
