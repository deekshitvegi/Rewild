# Reaper concepts

Concept pictures for the Reaper, the Harrow's fighter (first fight, milestone 4), made 8 Nov 2026 with Higgsfield
GPT Image 2.6 (concept art only; the model is built from code in art/reaper). Three directions, two renders each,
all in the Harrow's material: dark cast alloy with hot seams where the ore runs.

- `reaper-concept-sickle-*.png`: two crescent blades curving forward past the nose. **The owner chose this one**
  (sickle-2 is the reference; sickle-1 is a second view of the same idea).
- `reaper-concept-wasp-*.png`: a segmented insect body with four blade fins and a split prong nose.
- `reaper-concept-shard-*.png`: a flat faceted arrowhead with a furnace slot engine.
- `reaper-concepts-sheet.jpg`: the sheet the owner chose from.
