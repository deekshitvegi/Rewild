# The opening film (web version): script v1, 9 Nov 2026

Replaces the Higgsfield (AI) opening films, which the owner disliked ("looks like AI generated video... rebuild a
video by yourself from the game... maybe a longer video so the game loads properly behind because the video was
lagging a lot too"). Made from the game itself: every frame rendered by the engine on a virtual clock, then encoded,
so the film never stutters however busy the computer is while the game loads behind it. Per ASSET_JOB.md: this
script and one still per shot go to the owner first; the film is rendered only after they approve.

New players (opening at Haven), about 60 s, 1920x1080, 30 fps:
